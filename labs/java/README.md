# Java projects

Four independent Java 17+ console applications, each using only the JDK.

In the individual project directory run:

```bash
javac Main.java
java Main
java -ea Main --self-test
```

Projects: BigDecimal financial ledger with atomic transfers; Dijkstra route planner; generic LRU cache; and password policy validator. All data is synthetic and local. No banking connection or real credentials are involved.
