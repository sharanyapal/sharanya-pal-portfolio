# Python showcase

Seven independent, runnable projects demonstrate IAM governance, citation-grounded retrieval and optional LLM integration, ML text classification, reproducible model comparison, statistical anomaly detection, async HTTP monitoring, and integrity verification.

Run a project from its own directory; e.g. `python main.py`. Install `pip install -r requirements.txt` only for projects with that file. Tests: run `python -m pytest -q` inside each individual project directory after installing `pytest scikit-learn httpx`.

The data is synthetic or public toy data. No live client, employee, or bank information is included. API-based LLM access is optional and requires your own credentials in environment variables—never commit API keys.
