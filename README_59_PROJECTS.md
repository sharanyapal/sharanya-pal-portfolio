# Sharanya Pal — 59-project cinematic polyglot portfolio

Production website: https://sharanya-pal-cinematic-portfolio.vercel.app/

The portfolio has two compact horizontally scrollable project shelves plus a collapsible archive. This revision introduces four additional finance/marketing experiences (59 total source projects: 24 original + 15 advanced + 16 polyglot + 4 finance labs):

- **BankTrace Fraud Network** — synthetic transfer graph signals, deposit velocity, concentration and circular payments.
- **CreditSense Underwriting** — synthetic classification via SGD logistic regression, holdout test, coefficient inspection.
- **Market Regime Radar** — Gaussian two-state hidden Markov model and forward/backward EM updates.
- **GrowthLift Studio** — difference-in-differences and bootstrap uncertainty with confounder sensitivity.

Go, R, MATLAB/Octave, C, C#, Ruby, MongoDB, TypeScript, Python/Selenium and Java projects remain in their respective source directories. Browser demos are educational models using synthetic data; they do not claim real lender approvals, real-time stock prices or real-world fraud verdicts.

**Deployment:** Vercel production builds require account access. A successful GitHub commit does not itself guarantee the Vercel alias has deployed.
