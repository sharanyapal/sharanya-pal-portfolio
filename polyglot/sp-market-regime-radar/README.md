# MARKET REGIME RADAR

Fit a two-state Gaussian hidden Markov model for volatility regimes

This is a dependency-free browser research prototype. It runs on synthetic data and should not be used for lending, trading or operational security decisions.

Portfolio entry: https://sharanya-pal-cinematic-portfolio.vercel.app/polyglot/sp-market-regime-radar/ (available when the latest commit has actually been deployed).
